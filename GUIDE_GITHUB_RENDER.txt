PING! V0.34 — MISE À JOUR GITHUB + RENDER

1. DÉCOMPRESSE LE ZIP

2. OUVRE LE DOSSIER
   PING_V0_34_GITHUB_RENDER_BOTS

3. DANS TON DÉPÔT GITHUB "ping"
   Dépose le CONTENU de ce dossier à la racine.
   Remplace les anciens fichiers lorsqu'on te le demande.

   Vérifie en particulier que ces fichiers sont à la racine :
   - index.html
   - server.js
   - package.json
   - render.yaml
   - fond_ping_aquarelle.png

4. FAIS LE COMMIT

5. RENDER
   Si ton service Render est déjà relié à ce dépôt et Auto Deploy activé :
   aucune nouvelle configuration n'est normalement nécessaire.
   Le déploiement doit se lancer après le commit.

   Sinon :
   - Build Command : npm install
   - Start Command : npm start
   - Health Check : /health

6. TEST
   - vérifie d'abord BOT facile ;
   - vérifie BOT intermédiaire V2 ;
   - puis teste une salle Joueur contre Joueur avec deux appareils.

À NE PAS FAIRE
- ne mets pas node_modules sur GitHub ;
- ne lance pas le fichier .bat sur Render ;
- ne remplace pas PORT par un numéro fixe dans server.js.
